# 서가의 별자리 — 배포 안내

2026 도서관 데이터 활용 공모전 · 융합콘텐츠 제작 부문 시연용
AI 해설: Google Gemini API

---

## 먼저 알아둘 것

**핵심 기능은 API 없이 전부 동작합니다.** 그래프, 4개 영역 전환, 3단계 시연,
사서 검토 워크플로우, 검색 — 모두 데이터가 앱에 내장돼 있어 네트워크가 없어도 돕니다.

API가 필요한 곳은 **「이 주제명 해설 보기」 버튼 하나**뿐입니다.
원고 `<표 12>`에 "AI는 해설문 생성에만 사용"이라고 명시한 바로 그 기능입니다.

> **발표 당일 권고** — 라이브 시연에서는 해설 버튼을 누르지 마십시오.
> 대회의실 네트워크가 불안정하면 20초를 기다리게 됩니다.
> 심사위원이 배포 URL을 직접 열어볼 때 동작하면 충분합니다.

## 1단계. Gemini API 키 발급 (3분)

1. https://aistudio.google.com/apikey 접속 (구글 계정 로그인)
2. **Create API key** 클릭
3. 키 복사 — `AIza...` 로 시작합니다

무료 등급으로 충분합니다. 해설 한 번에 약 500토큰이라 시연 용도로는 부담이 없습니다.

## 3단계. 환경변수 등록 ★ 가장 자주 실수하는 곳

Vercel 대시보드 → 프로젝트 → **Settings → Environment Variables**

| Key | Value | Environment |
|---|---|---|
| `GEMINI_API_KEY` | `AIza...` | Production · Preview · Development **모두 체크** |
| `GEMINI_MODEL` | `gemini-2.5-flash` | (선택) 모델을 바꾸고 싶을 때만 |

> ### 등록만 하면 적용되지 않습니다. 반드시 재배포하십시오.
> **Deployments → 맨 위 항목 → ⋯ → Redeploy**
>
> 환경변수는 빌드 시점에 주입되므로, 등록 후 재배포하지 않으면 계속 500 오류가 납니다.

## 4단계. 배포 후 점검 (3분)

- [ ] 그래프가 뜨고 노드가 자리를 잡는가
- [ ] 영역 탭 4개 전환 — 대중음악 / 문학 / 한국전쟁 기록 / 시험·실무
- [ ] 1 → 2 → 3 단계 전환 시 선이 바뀌는가
- [ ] 3단계에서 「채택」 → 1단계 복귀 시 **없던 선이 생기는가** ← 시연의 핵심
- [ ] 우측 「영향 도서」 수치가 올라가는가
- [ ] 검색창에 "가요" 입력 → 목록이 걸러지는가
- [ ] 노드 클릭 → 「이 주제명 해설 보기」 → 해설이 나오는가

## 문제 해결

브라우저 개발자도구(F12) → **Network** 탭에서 `/api/explain` 응답을 확인하십시오.

| 증상 | 원인 | 해결 |
|---|---|---|
| `500` · GEMINI_API_KEY 미설정 | 환경변수 누락 또는 재배포 안 함 | 3단계 재확인 후 **Redeploy** |
| `400` 또는 `403` | 키가 잘못됨 / 사용 설정 안 됨 | AI Studio에서 키 재발급 |
| `404` · 모델을 찾을 수 없음 | 모델명이 바뀜 | 아래 명령으로 확인 후 `GEMINI_MODEL` 수정 |
| `429` | 무료 등급 한도 초과 | 잠시 후 재시도 |
| `404` · 페이지 자체 없음 | `api/` 폴더 위치 오류 | 프로젝트 **루트**에 `api/explain.js` 가 있어야 함 |

### 사용 가능한 모델 확인하기

```bash
curl -s "https://generativelanguage.googleapis.com/v1beta/models" \
  -H "x-goog-api-key: 발급받은키" | grep '"name"'
```

목록에 나온 이름에서 `models/` 를 뗀 값을 `GEMINI_MODEL` 에 넣으면 됩니다.
예를 들어 `models/gemini-2.5-flash` → `gemini-2.5-flash`

## 5단계. 발표 당일

**브라우저 준비**
- 미리 URL을 열어 캐시를 채워두십시오
- 브라우저 확대 100% (Ctrl+0)
- F11 전체화면

**네트워크가 끊겨도**
페이지가 이미 열려 있으면 해설을 제외한 모든 기능이 정상 동작합니다.
발표 전 미리 열어두는 것만으로 대부분의 사고가 예방됩니다.

**최후 대비**
데모가 아예 안 뜰 경우를 대비해 화면 캡처를 발표자료 뒤에 넣어두십시오.
